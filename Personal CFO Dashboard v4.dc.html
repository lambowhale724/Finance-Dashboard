One-time setup — about five minutes, done once
  1. Go to supabase.com, sign up free, and create a project. Any name, any region near you.
  2. In the left sidebar open SQL Editor, paste the block below, and press Run.
  3. Open Project Settings → API. Copy the Project URL and the anon public key into the two fields above.
  4. Name this device (iPhone, iPad, MacBook) and press Connect and sync. Your current numbers upload.
  5. On each other device, open the same dashboard URL, paste the same two values, name that device, and connect. It pulls the shared copy down.
create table if not exists cfo_state (
  id text primary key,
  rev bigint default 0,
  device text,
  updated_at timestamptz default now(),
  data jsonb
);
alter table cfo_state enable row level security;
create policy cfo_state_open on cfo_state
  for all to anon using (true) with check (true);

The anon key sits in this page, so treat the dashboard URL as private — anyone who has both can read the record. For a single private planning file that trade is usually worth the convenience; if it ever stops being worth it, rotate the key in Supabase and this dashboard disconnects.
